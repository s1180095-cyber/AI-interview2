# AI 模拟面试 · 四屏交互原型

根据四张设计稿（首页、AI 题库、面试中、面试结果报告）还原的响应式交互网站。纯静态、零依赖、无需构建，可直接部署到 GitHub Pages。

## 已实现功能

- **首页**：AI 模拟面试入口、今日进度、连续打卡、即将开始、核心功能入口
- **AI 题库**：关键词搜索、分类筛选、今日进度、题目列表、收藏、随机练习
- **面试中**：AI 面试官动效、语音波形、计时/暂停、示例回答、回答模板、提交后自动进入下一题
- **面试报告**：综合得分仪表盘、能力雷达图、维度得分、亮点/建议展开、AI 评语、报告导出
- **导航**：底部标签栏、左侧屏幕切换器、键盘 `1` / `2` / `3` / `4` 快速切屏，`Esc` 返回首页
- **适配**：桌面端展示手机模型与项目说明，移动端自动全屏

## 目录结构

```
.
├── index.html          # 页面入口，包含四屏结构与图标
├── css/style.css       # 全部视觉样式与响应式布局
├── js/app.js           # 导航、题库、面试、报告等交互逻辑
├── .nojekyll           # GitHub Pages 静态资源兼容
└── README.md           # 运行与部署说明
```

## 本地运行

直接双击 `index.html` 即可打开。推荐启动本地服务器：

```bash
cd /Users/Yolanda/CodeBuddy/20261125
python3 -m http.server 8000
```

访问 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，例如 `ai-mock-interview`。
2. 将本目录中的 `index.html`、`css/`、`js/`、`.nojekyll` 上传到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。
5. 等待部署完成后访问 `https://<用户名>.github.io/ai-mock-interview/`。

所有资源均使用相对路径，无需配置 GitHub Actions 或构建脚本。

## 交互提示

- 首页点击「开始面试」进入完整答题流程，答完 4 题自动生成报告。
- 题库中点击题目卡片可查看详情、收藏或直接开始练习。
- 面试页工具栏依次可生成示例回答、插入回答模板、查看框架、添加模拟附件、提交回答。
- 报告页点击亮点/建议可展开详细说明，右上角分享按钮可导出 `.txt` 报告。
